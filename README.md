# CW Portfolio — стартовый проект

## Что уже подготовлено

- Главная страница портфолио.
- Фиксированные разделы и подразделы, расположенные друг под другом.
- Общая masonry-галерея с сохранением исходных пропорций изображений.
- Увеличение работ в модальном окне поверх сайта.
- Строка статусов заказов в формате `... | ...`.
- Настройки логотипа, ссылок и статусов через Pages CMS.
- Автоматическая дата по последнему коммиту с изменениями файлов портфолио.
- В конфигурации загрузок разрешены PNG, JPG, JPEG, WEBP, GIF, APNG и SVG.

## Структура

- `.pages.yml` — конфигурация Pages CMS.
- `data/site.json` — настройки шапки и информации о заказах.
- `data/*.json` — списки работ по разделам.
- `images/` — загружаемые изображения.
- `index.html`, `style.css`, `script.js` — сайт.

## Установка в GitHub

1. Распакуй архив.
2. Загрузи содержимое папки проекта в корень репозитория `TsarII/cw-portfolio`.
3. Если GitHub спросит о совпадающих файлах, не перезаписывай ничего, что хочешь сохранить; сначала проверь содержимое репозитория.
4. В настройках репозитория открой **Settings → Pages** и проверь публикацию из ветки `main`, папка `/ (root)`.
5. Дождись публикации GitHub Pages.

## Подключение Pages CMS

1. Открой Pages CMS и войди через GitHub.
2. Выбери репозиторий `TsarII/cw-portfolio` и ветку `main`.
3. Pages CMS должен прочитать `.pages.yml`.
4. В меню появятся «Настройки сайта», «Костюмы», «Предметы», «Медали», «Иллюстрации» и «Фоны».

## Как добавлять работы

Открой нужный раздел в Pages CMS и добавь элемент списка:
- Изображение — загрузи оригинальный файл.
- Название — необязательно.
- Подпись — необязательно.
- Порядок — число; меньшие значения идут раньше.

Не конвертируй APNG в GIF или PNG: сайт выводит исходный файл обычным HTML-изображением, поэтому браузер может воспроизводить анимацию APNG.

## Важное про дату

Дата рассчитывается по последнему коммиту GitHub в файлах со списками работ. Поэтому добавление или изменение записи портфолио обновляет дату автоматически. Для запроса даты используется публичный GitHub API; репозиторий должен быть доступен публично. Если API временно недоступен или ограничил запросы, сайт покажет запасной текст.

## Важное про APNG

Расширение `apng` добавлено в список разрешённых форматов Pages CMS. Это разрешает загрузку на уровне конфигурации, но окончательную поддержку нужно проверить непосредственно в интерфейсе Pages CMS после загрузки первого APNG. Сам сайт не обрабатывает и не перекодирует изображения.
